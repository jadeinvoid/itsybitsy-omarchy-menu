# Itsybitsy Menu for Omarchy

An Omarchy menu plugin with randomized colors from the Itsybitsy palette.

## Features

- Random selection color when navigating the menu
- Matching color accents for the selected icon and arrow
- Subtle translucent selection background
- Automatic replacement and restoration of the built-in Omarchy menu

## Installation

```bash
omarchy plugin add https://github.com/jadeinvoid/itsybitsy-omarchy-menu.git --enable
```

## Companion theme

Designed for [Itsybitsy for Omarchy](https://github.com/jadeinvoid/itsybitsy-omarchy-theme),
but it can be used independently.
